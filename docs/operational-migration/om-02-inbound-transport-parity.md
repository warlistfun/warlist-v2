## Exact Baileys v6.7.23 provider contract

- `package.json` and the lockfile pin exactly `@whiskeysockets/baileys@6.7.23`.
- Official package `lib/Types/Events.d.ts` defines `messages.upsert` as `{ messages: WAMessage[]; type: 'append' | 'notify'; requestId?: string }`; its comment says online receipt uses `notify` and `requestId` means receipt from the phone while it was unavailable.
- `lib/Types/Message.d.ts` defines `WAMessage` over `proto.IWebMessageInfo` with a required `key`; the key extension includes PN/LID sender and participant projections.
- `WAProto/index.d.ts` exposes optional key `id`, `remoteJid`, `participant`, `fromMe`; `messageTimestamp` as number/Long; `conversation`, `extendedTextMessage`, and `contextInfo.quotedMessage`.
- These declarations verify the decoder input contract, not live provider delivery, ordering, reconnect, or account behavior.
