## Delivered boundary

- IPC v1 adds exact empty-payload `RESET_WORKER` commands and empty-payload acknowledgements with existing request/correlation/tenant/generation/child identity checks.
- `WorkerRuntimeService.resetWorker()` uses the existing per-tenant command queue, exact pending identity, timeout, diagnostics, and retry behavior.
- The Baileys child marks the exact worker stopped, advances its epoch, cancels reconnect work, removes listeners, closes the socket, runs reset and release serially, and acknowledges only after both complete.
- The local credential capability owns the only recursive deletion call. A started-but-incomplete reset cannot fall back to ordinary release, transfer ownership, or resume credential use.
- The concrete transport releases the old child only after an exact matching terminal stop/reset acknowledgement, allowing a new generation to start.
- No HTTP/admin/operator reset surface was added; that remains a later operational-application slice.
